# Polygon Art with Turtle Graphics

This program uses Python's `turtle` module to draw colorful polygon art
(triangles, squares, pentagons) with different styles selected by the user.

## Requirements

- Python 3 (I tested with Python 3.13.x from Homebrew)
- The `turtle` module (comes with the standard library)
- A working Tkinter installation (needed for the turtle graphics window)

On macOS with Homebrew Python you may need:

```bash
brew install python@3.13
brew install python-tk@3.13
